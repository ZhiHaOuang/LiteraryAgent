# LG Memory Templates

`lg init` does not create empty memory files. Supplemental notes are created
only when useful, in the current book's `ReferenceLibrary/bible/`.

Optional note filenames are (the project database is authoritative):

- `CHARACTERS.md`
- `LOCATIONS.md`
- `WORLDVIEW.md`
- `PLOT_POINTS.md`
- `TIMELINE.md`
- `RELATIONSHIPS.md`
- `STYLE_GUIDE.md`
- `ERRORS.md`
- `STORY_BIBLE.md`

Memory updates should separate durable canon from brainstorm notes and failed ideas.
