# LG Memory Templates

`lg init` creates runtime memory files in `.literarygiant/memory/`.

The canonical memory files are:

- `CHARACTERS.md`
- `LOCATIONS.md`
- `WORLDVIEW.md`
- `PLOT_POINTS.md`
- `TIMELINE.md`
- `RELATIONSHIPS.md`
- `STYLE_GUIDE.md`
- `ERRORS.md`
- `STORY_BIBLE.md`

Memory updates should separate durable canon from brainstorm notes and failed ideas.
